# Gomoku Project
It was my first project in Python. It's a game called Gomoku, that I had to build as an assignment in college. Basically, it's played on a Go board with mechanics similar to Connect Four (without the physics/gravity). You have to place five pieces in a diagonal, line or column to win the game. All the files will be in Portuguese.
